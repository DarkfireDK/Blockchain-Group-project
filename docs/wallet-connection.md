# 钱包账户未授权（4100）

这不是ERC20 allowance不足。请在同一个网站地址使用钱包，例如固定使用 http://127.0.0.1:3000 。localhost、127.0.0.1、不同端口分别需要网站授权。

1. 重启前端并刷新页面，在“我的钱包”点击“重新连接钱包”。
2. 解锁MetaMask，选择需要使用的账户，确认连接。页面地址应与MetaMask授权账户一致。
3. 本地模式钱包网络为Hardhat，chain ID 31337，RPC http://127.0.0.1:8545 。先领取本地测试ETH，再领取测试USDC。
4. 若仍报4100，在MetaMask的已连接网站/网站权限中移除当前网站连接，再从页面重新连接并明确选择账户。

修复内容：领取前检查当前连接器实际暴露的账户与网络；写交易显式绑定账户、连接器和网络；确认交易时使用相同网络RPC；失败时提供重连入口，未取得交易哈希不会再显示领取成功。
